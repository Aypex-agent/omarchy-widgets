# Car Maintenance

An offline vehicle maintenance and reminder widget for OmaLauncher.

## Features

- Manage multiple vehicles
- Track MOT, insurance, servicing and other deadlines
- Date-based and mileage-based reminders
- Record maintenance history
- Update vehicle odometers
- Customizable reminder thresholds
- Read-only lock
- Miles and kilometres supported
- All data saved locally; no internet required
- Adapts to different widget sizes

## Getting Started

1. Add the widget to your OmaLauncher home screen.
2. Tap to add your first vehicle.
3. Add maintenance reminders and due dates.
4. Update your odometer as needed.
